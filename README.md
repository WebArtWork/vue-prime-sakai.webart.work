Sakai is an application template for Vue based on [create-vue](https://github.com/vuejs/create-vue), the recommended way to start a Vite-powered Vue project.

This copy is maintained by Web Art Work and builds on [vue-prime](https://github.com/WebArtWork/vue-prime) (`@wawjs/vue-prime`), the independent MIT-licensed continuation of the PrimeVue v4 codebase, together with [css-prime](https://github.com/WebArtWork/css-prime) themes.

## Development

```bash
npm install
npm run dev
```

```bash
npm run build
```
